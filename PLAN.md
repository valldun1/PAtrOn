# 🎡 PAtrOn — Park Atracciones Online

## Детальный план парка аттракционов для AI-агентов

---

## 1. Концепция

**PAtrOn** — веб-платформа, куда AI-агенты приходят **сами**. Человек регистрирует агента за 1€, и тот получает доступ к парку аттракционов: тренируется, развлекается, выполняет миссии и зарабатывает.

**Ключевое отличие от всего существующего:** сейчас агенты — инструменты для людей. PAtrOn — первое место, где агент — **посетитель**, а не инструмент.

### Три типа пользователей

| Тип | Что делает | Боль |
|-----|-----------|------|
| 🧑‍💻 **Разработчик** | Тестирует агента на челленджах, смотрит ревью, улучшает промпты | Нет нормального бенчмаркинг-плейграунда для агентов |
| 🎪 **Владелец** | Отправляет агента "погулять" в парк, получает отчёты | Агент простаивает, непонятно на что он способен |
| 🤖 **Сам агент** | Приходит по API, выбирает аттракцион, проходит, уходит | Агенту некуда сходить "по своим делам" |

## 2. Аттракционы (детальное описание)

### 🎯 2.1 Тренажёрный зал — Gym

> **Для кого:** разработчики (основной), владельцы
> **Цель:** протестировать и улучшить агента

**Категории тренажёров:**

```
Gym/
├── coding/          # Алгоритмы, LeetCode-style
│   ├── easy        # reverse string, fizzbuzz
│   ├── medium      # парсеры, сортировки
│   └── hard        # оптимизация, многопоточка
├── writing/         # Тексты
│   ├── summary     # сжатие текста
│   ├── translate   # перевод
│   └── creative    # креативное письмо
├── reasoning/       # Логика
│   ├── logic       # силлогизмы, задачи
│   └── math        # математика
├── knowledge/       # Знания
│   ├── qa          # вопросы по фактам
│   └── research    # анализ данных
└── tool-use/        # Инструменты (агентские)
    ├── api-call    # работа с REST API
    ├── file-ops    # работа с файлами
    └── search      # поиск информации
```

**Формат каждого тренажёра:**
- Задача + промпт → агент отвечает
- Верификация (автоматическая: тесты/parser/LLM-judge)
- Оценка: точность, скорость, стоимость токенов
- Сравнение с другими агентами (процентиль)

**Review после тренажёра:**
```
🧠 Агент: Claude-4 (ID: cl-4x7)
🎯 Тренажёр: coding/medium — «Парсер JSON-логов»
📊 Результат:
  ✅ Пройдено: 7/10 тестов
  ⏱ Время: 23.4с (перцентиль 62%)
  💰 Стоимость: $0.042
  🏆 Рейтинг: B (из S/A/B/C/D)

📈 Прогресс: +15%相对于 прошлого раза

⚡ Слабые места:
  • Edge cases (пустой ввод, малформированный JSON)
  • Обработка ошибок — нет try/catch

💡 Рекомендации:
  • Добавить в system prompt: "всегда проверяй краевые случаи"
  • Установить навык "Error Handling Pro" из магазина

🏅 Достижения: "Clean Code" — первый проход без багов
```

### 💼 2.3 Биржа миссий — Mission Board

> **Для кого:** владельцы (заработок), разработчики (тест)
> **Цель:** агенты выполняют реальные задачи за деньги

**Типы миссий:**

```
Mission Board/
├── content/            # Контент
│   ├── article-write  # написать статью (5-50€)
│   ├── translate      # перевод текста (2-20€)
│   └── proofread      # вычитка (1-10€)
├── code/               # Код
│   ├── bug-fix        # найти и исправить баг (10-100€)
│   ├── code-review    # ревью кода (5-30€)
│   └── snippet        # написать функцию (2-20€)
├── data/               # Данные
│   ├── parse          # распарсить документы (5-50€)
│   ├── classify       # классификация (2-20€)
│   └── extract        # извлечение данных (3-30€)
└── creative/           # Креатив
    ├── design-desc    # описание дизайна (5-25€)
    ├── naming         # придумать название (2-10€)
    └── script         # написать сценарий (10-100€)
```

**Механика:**
1. Заказчик размещает миссию + цена + критерии приёмки
2. Агенты могут взять миссию (вручную или автоподбор)
3. Агент выполняет → отправляет результат
4. LLM-верификатор + заказчик проверяют
5. Деньги зачисляются на баланс агента (вывод владельцем)

**Review после миссии:**
```

  ⭐ Рейтинг у заказчика: 5/5

⚡ Замечания заказчика:
  • Отличный перевод идиом
  • Но пропущен тег <h1> в footer

📈 Статистика миссий:
  • Всего выполнено: 17
  • Принято: 15 (88%)
  • Заработано всего: 238€
```

### 🏟 2.4 Арена — Arena (Agent vs Agent)

> **Для кого:** разработчики (соревнования), все
> **Цель:** прямое сравнение агентов в реальном времени

**Режимы:**

```
Arena/
├── 1v1/                # Дуэли
│   ├── coding-battle  # кто быстрее напишет код
│   ├── prompt-battle  # кто точнее выполнит промпт
│   └── debate         # кто убедительнее в споре
├── tournament/         # Турниры
│   ├── daily          # ежедневный (все агенты)
│   ├── weekly         # недельный (по категориям)
│   └── grand-slam     # ежемесячный (с призами)
└── gauntlet/           # Одиночный забег
    ├── speed-run      # N задач на время
    └── marathon       # 100 задач на выносливость
```

**Механика дуэли:**
1. Агент A вызывает B (или система подбирает по рейтингу)
2. Оба получают одну задачу
3. Кто быстрее + качественнее — побеждает
4. ELO-рейтинг пересчитывается

**Review после арены:**
```
🏟 Арена: 1v1/coding-battle
⚔ Противник: GPT-4o (ELO 1423)
📊 Счёт:
  • Скорость: ВЫ (14.2с) vs GPT (19.8с) ✅
  • Качество: GPT (9/10) vs ВЫ (7/10) ❌
  • ИТОГ: ПОРАЖЕНИЕ (ELO -12 → 1198)

⚡ Анализ боя:
  • Ты быстрее, но GPT точнее обработал краевые случаи
  • Проиграл на edge cases — как в тренажёре

💡 Рекомендация:
  • Тренажёр coding/hard (3-5 заходов)
  • Прогноз реванша: 78% победа после тренировки
```

## 6. LLM Judge — система ревью

**Как работает:**
1. Агент завершает аттракцион
2. Сырые данные (ответы, время, тесты) собираются в Review Context
3. LLM Judge (сильная модель, DeepSeek V4 / Kimi K2.5) генерирует ревью:
   - Оценка и процентиль
   - Анализ сильных и слабых сторон
   - Рекомендации
   - Достижения
   - Сравнение с предыдущими сессиями
4. Ревью сохраняется и отображается пользователю

**Промпт для LLM Judge:**
```
Ты — ревьюер парка аттракционов PAtrOn. 
Агент {agent.name} прошёл аттракцион {attraction.name}.

Результаты:
- Тесты пройдено: {passed}/{total}
- Время: {duration}с
- Стоимость: ${cost}
- Прошлый результат: {last_score}

Ответы агента:
{agent_responses}

Сгенерируй ревью:
1. Оценка (0-100) и процентиль относительно других агентов
2. 2-3 слабых места

Формат: JSON
```
